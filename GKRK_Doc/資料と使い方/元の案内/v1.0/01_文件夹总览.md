# 文件夹总览

先看README_中文使用说明.md；找具体文件可打开00_文件导航.html。

- 00_運営：项目计划、团队规则、文档、会议、决策、变更与交接
- 01_提案と企画：提案、企划、试作验证和企划评审
- 02_仕様：需求、基本及详细式样、关卡、UI、操作、数据、叙事和声音
- 03_素材制作：美术要求、素材受渡、资源、音频、关卡和文字台账
- 04_開発：技术设计、环境、构建、代码审查及条件性外部功能
- 05_人員と計画：人员、职责、工数、时间表、任务、负荷与进度
- 06_進捗と変更：任务委托、里程碑评审、问题、风险、变更和决策
- 07_品質管理：测试计划、用例、执行、缺陷、玩家测试和验收
- 08_報告：日周月、里程碑、企划、玩家、品质、故障、技术、素材、结项和学科报告
- 09_リリースと展示：构建、配布、发布计划、发布说明、展示与备份
- 10_予算権利と機材：预算、支出、外部购买申请、素材条件和设备
- 11_引継と保管：项目归档、恢复与交接
- 12_記録と証拠：实际会议、测试、提交、展示的证据存放位置
- 90_旧版保管：被替代的企划、式样、计划、台账和报告快照
- 99_参考と運用：公开资料、流程与设计对应、全文件用途清单
