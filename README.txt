GKRK 制作資料

GKRK_Cfg：ゲームの設定表・数値表を保存します。
新規・変更データはData_Betaで確認し、テスト後にDataへ反映します。

GKRK_Doc：企画書、仕様書、制作依頼、制作管理、日報・週報、テスト、展示、引継ぎの資料を保存します。
日常の管理書類はGKRK_Doc/README_PM.txt、文書の保存先はGKRK_Doc/文書一覧.txtを確認してください。
担当・期限・進捗はGKRK_Doc/制作管理/制作管理.xlsxで管理します。

GKRK_Shape：グラフィック・音素材を保存します。
各分類のBuildにゲーム用の書き出しデータ、Sourceに編集可能な元データと必要な依存ファイルを保存します。
BuildとSourceは同じ素材・同じ版でそろえます。

空の保存先には.gitkeepを置いています。素材やデータを追加した後も、そのまま残して構いません。

中文说明
配置表放在GKRK_Cfg，策划与制作管理文档放在GKRK_Doc，美术与音频资源放在GKRK_Shape。
配置表先在Data_Beta测试，通过后更新Data。美术资源同时提交对应版本的Build和Source。
当前进度统一记录在制作管理.xlsx；旧版和记入例作为参考保存，不重复维护同一任务。
