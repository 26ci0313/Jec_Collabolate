# 使用说明

先用这五份文件。正文是日文，填写提示是中文。

1. 人员管理：「メンバーと担当.xlsx」每人填一行，写姓名、负责岗位、负责的工作和能参加的时间。
2. 进度确认：「作業予定と進捗.xlsx」每项工作填一行，写负责人、计划日期、状态、问题和下一步。
3. 报告：「日報.docx」写当天，「週報.docx」写本周，「作業の区切り報告.docx」写一阶段结束时的情况；三份都只有一页，按需要选用。

Excel 状态：未着手＝未开始、作業中＝进行中、完了＝完成、保留＝暂时搁置。日期按 yyyy-mm-dd 填写。姓名、日期、工作和结果留空，等实际使用时填写。

样式参照你提供的「主要功能测试分配.xlsx」表头及「盛世芳华3版本规划.xlsx」的「项目流程规划（旧）」表格：直接列字段、负责人和备注，保留绿色、橙色、浅蓝的表格特点。字段按本次人员与进度用途调整；日期栏和三份报告是本次自用设计。原件未改动，未复制原人员或项目内容。原资料未标明统一发布日期，本次查看日期为2026-10-03。
