游戏制作管理文件 v3.0 中文使用说明

新增 8 份日常实务书式，依据你提供的游戏制作资料重新设计名称、布局与填写关系。保留 v2.0 全套资料作为配套：本包共 77 份 Word、17 份 Excel、82 个工作表，X01 登记 94 份文件。

开始使用

1. 打开 文件导航 (00_文件导航.html)，优先使用下表的实务书式。
2. 在 X02 设置真实成员，在 X03 设置任务、可用时间和计划，在 X09 设置实际构建与配布条件。未定内容保持空白或注明待确认。
3. 将 F01 按功能、F02 按制作批次、F03 按配置变更、F04 按不具合复制到项目工作目录。模板原件保留。本包不预设游戏、成员、日期、引擎和分支名。
4. 使用真实成果与证据填写记录；把当前状态同步到对应主台账，再登记实际判断与提交。模板中的条件和检查项目不是已经发生的实绩。

日常入口

书式：用途
F01 機能設計ブック (15_実務書式/01_機能設計/F01_機能設計ブック.xlsx)：把功能目的、玩家操作、完整规则、界面、配表和验收写在同一个工作簿。按功能复制使用。
F02 制作連携シート (15_実務書式/02_制作連携/F02_制作連携シート.xlsx)：安排一次制作批次，交接原始资源、依赖文件和配置，再记录分支测试、合并确认与受领。
F03 設定更新確認表 (15_実務書式/03_設定更新/F03_設定更新確認表.xlsx)：记录一次配表变更的字段、ID和引用关系；留下编辑占用通知与提交前检查证据。
F04 不具合報告シート (15_実務書式/04_不具合/F04_不具合報告シート.xlsx)：先报告现象、版本和重现步骤，再分别记录开发回应与复测；当前BUG状态仍以X07为准。
D01 共通書式と運用規約 (15_実務書式/00_共通運用/D01_共通書式と運用規約.docx)：查看新版的共同填写、命名、正本、交接和核查规则。正文是供团队采用的初始运用案。
D02 週次連携報告 (15_実務書式/01_週次連携/D02_週次連携報告.docx)：汇报一周的已确认成果、阻塞、所需判断和下一周行动；数字引用主台账，不重复记工时。
D03 作業依頼・受渡票 (15_実務書式/02_依頼と受渡/D03_作業依頼・受渡票.docx)：提出一次跨职种作业请求，随后单独确认实际交付、检查与受领。
D04 実施記録 (15_実務書式/03_実施と証拠/D04_実施記録.docx)：记录会议、评审、试玩或培训的实际情况、决定和后续行动。

主台账

内容：唯一当前正本：实务书式中的记录
文书版本、正式审查、提交和受领：X01 文書管理台帳：D/F 引用相应记录，检查栏不代替正式决定
成员与角色：X02 人員管理台帳：仅引用成员ID
任务担当、期限、状态与工时：X03 制作計画進捗台帳：F02 定义本批次次序与交接条件，D02 引用统计截止日
需求与规格关联：X04 要件仕様管理台帳：F01 保存详细功能设计，X04保存追踪关系
资源当前状态：X05 素材制作管理台帳：F01提出需求，F02保存一次交接的原本、导入物与依赖
问题、风险、变更与决定：X06 課題リスク変更台帳：只引用ISS、RSK、CHG、DEC
测试案例、执行与BUG当前状态：X07 テスト不具合管理台帳：F01写功能验收条件，F02/F03/F04保存一次执行证据
构建、配布与备份：X09 ビルド配布運用台帳：引用BLD、环境与实际受领

这些文件没有自动同步。一次执行可有自己的详细记录；同一个任务或BUG的“当前状态”只在相应主台账维护。报告引用正本并注明截止日。

原有文件如何使用

原有管理、人员、计划、报告、连络、准备和保管文件全部保留。新 F01 可作为日常功能设计正本；项目如果采用 F01，不再为同一功能重复填全部 S01–S09，专项规格只在确有需要时使用并互相引用。F02/F03/F04是工作单元的详细记录，不能替代 X03/X05/X07 等全项目台账。D02可作为常用周报；R02留作学校或项目要求的正式提交报告。D03与D04用于普通依赖交接和实施记录，专业测试、事故与阶段报告按需使用。

填写和扩展

Excel 淡黄色是输入，淡青色是计算，灰底是说明。输入日期使用真正的日期值，格式为 yyyy-mm-dd；日時为 yyyy-mm-dd hh:mm。空白不等于0、合格或已批准。证据使用项目内相对路径或关联记录ID。图片框留给实际画面、流程图与重现证据。

表格预留40行，预填的核查标准是初始建议。增加行时同时延长Excel表、输入规则和公式范围；编号重复检查只覆盖同一表的当前范围，跨表和跨工作簿仍需检查对应正本。表中筛选从真实列标题开始，字段提示位于表外。

本包代码 D、F、M、X 等均为自行设计的文书索引，不是日本游戏公司的统一编号。名称与结构依据你授权参照的工作方式重新组织。资料原件未复制进本包；未导入原公司项目数据、人员、图片或脚本。

正文使用日文，本文及参考说明使用中文。正文初始规约为 v0.1 未承认，实际记录为空。正式采用时按项目确定职责、条件和版本。完整来源对应见 自用书式与参考资料的对应 (99_参考と運用/自用书式与参考资料的对应.md)。

本包由已核对的 v2.0 配套文件与新增 v3.0 书式组成。新增书式的检查范围见 制作与核查记录 (99_参考と運用/制作与核查记录.md)。
