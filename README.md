# GKRK 制作資料

学科連携プロジェクトで使う企画・制作管理資料と、設定データ・素材の保存先です。

| フォルダー | 用途 |
| --- | --- |
| [GKRK_Cfg](GKRK_Cfg) | ゲームの設定表・数値表。Data_Betaで確認後、Dataへ反映します。 |
| [GKRK_Doc](GKRK_Doc) | 企画書、仕様書、依頼書、制作管理、日報・週報、テスト、展示、引継ぎの資料。 |
| [GKRK_Shape](GKRK_Shape) | グラフィック・音素材。各分類のBuildとSourceを同じ版でそろえます。 |

## 使い始めるとき

1. [PM書類の使い方](GKRK_Doc/README_PM.txt)で日常の管理書類を確認します。
2. [文書一覧](GKRK_Doc/文書一覧.txt)で必要な書式の保存先を探します。
3. 担当・期限・進捗は `GKRK_Doc/制作管理/制作管理.xlsx` にまとめます。

旧版と記入例は参考資料です。実際の進捗と混在させず、同じタスクを複数の台帳で重複管理しないでください。

空の保存先は `.gitkeep` で保持しています。
