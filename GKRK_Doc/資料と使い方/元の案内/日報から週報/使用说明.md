# 日报整理成一周报告

这组文件给策划使用：程序和美术每天提交带图片的日报，策划每周整理给老师看。正文日文，提示中文。目前没有实际日报和图片，以下是空白模板。

## 每周按三步做

1. **收日报**：在「策划整理用／日報と一週間のまとめ.xlsx」的「日報の整理」页，每人每天填一行，按日期由早到晚排列。写当天做了什么，保留原日报和图片的链接或保存位置。问题原文照抄；没写问题就留空，不当作“没有问题”。
2. **看每个人一周的情况**：同一本的「一週間のまとめ」页填共同起止日期，每人一行，写实际完成、未完成、确认过的问题、做过的帮助及结果、下周工作。连续几天卡住、内容含糊或需要单独了解的情况，另记在「策划内部用／困りごとと声かけ.xlsx」。
3. **写给老师的报告**：把本周总结填写到「先生提出用／先生提出用の週間活動報告.docx」，再按七天日期顺序填写每日记录并粘贴图片本身。每张图写日期、姓名、工作内容和比之前改变了什么；不要只放链接。向老师提交这份 Word。

## 内部跟进表怎么填

按“原话或看到的行为 → 可能原因（未确认） → 准备问什么 → 怎样帮助 → 谁跟进、什么时候再确认 → 本人回答和之后结果”填写。「声かけの例」页有四个虚构示例。「対応」先选准备做的事；实际做过后，在最后一格写实施日期、本人回答与结果，避免把计划当成已完成。

可以考虑先问一句、一起检查工作、个别谈话或向老师求助。对方直接表达的感受可以照实记录；没说清的动机或心理状态先标为未确认。不要只凭迟交、字数少或截图没变化，就认定消极或偷懒。选择「解決済み」前，确认问题确实解决，并填写之后的情况。

内部跟进表留给策划使用。老师报告写确认过的工作问题、影响、已做的帮助和需要的支援，不直接复制私人谈话或未确认的心理推测。

## 图片和日期

原图可按日期存入「先生提出用／画像」；一人多图时注明各图用途。图片只说明图上能看见的内容，不能自动等于“作业已经完成”。没有活动与没有收到日报分开写；只在确实确认无活动时写「活動なし」，未收到时写「日報未提出」，不要补造工作。

每周复制整组到该周文件夹。日期按 yyyy-mm-dd 填写，周起止按实际提交要求确定。成员多、图片多时，在同一日期下复制行或图片区；未使用的图片区删除即可。
