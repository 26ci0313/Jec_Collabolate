# 人员管理、进度确认与报告使用说明

当前范围为人员管理、进度确认及其报告。正文使用日文，说明使用中文。游戏提案、企划、仕様、配置表、美术、技术设计、测试质量和发行管理暂不纳入本包。此前的完整版本保留，不需要同时维护。

## 先使用哪些文件

1. 在「人员管理/人員管理台帳.xlsx」录入实际成员、参加期间、主担当、代理和交接，确认「役割RACI」中的实际责任人。周可用工时在进度台账的「稼働」填写。空白姓名与责任人不表示已经任命。
2. 在「进度确认/制作計画進捗台帳.xlsx」设置活动起点和确认基准，填写 WBS 的任务、担当、基准日期、预计工时与完成条件，再安排「週次配分」并对照「稼働」。保留原计划，通过预测日期和调整记录反映变化。
3. 活动后更新实际工时、剩余估计和任务状态；需要确认完成时记录成果路径、版本、确认日期与确认者。进度会记录问题、下一行动、责任人和期限，再从台账摘录对应报告。

这里给出的是可调整的初始运用建议，不代表团队已批准了报告频率、成员安排、期限或完成结果。实际项目名称、人员、日期、工时、确认结果和提交记录均待填写。

## 三本台账的分工

| 台账 | 记录正本 | 其他文书如何使用 |
|---|---|---|
| 人員管理台帳 | 成员和参加期间、角色责任、代理与交接现状 | 人员相关文书引用成员 ID 和对应行；休止安排及具体交接内容写入交接书，当前状态在成员备注保持一致 |
| 制作計画進捗台帳 | WBS、里程碑、基准与预测日程、工时、周配分、可用时间和汇总 | 会议和报告注明截止时间，引用任务 ID、台账版和成果证据；不会另建一套当前完成率 |
| 文書管理台帳 | 本包 18 份书式的路径、实运用版和报告确认、提交与受领 | 保存实际报告副本后登记相对路径和版本，提交日期与受领日期分别填写 |

「文書管理台帳」中的默认版是模板版。采用书式后，实际文书版、确认人、确认状态和日期另行填写。模板存在不表示已经执行或批准。报告是截止时点的记录，保留历史；发现事实变化后，先更新对应台账，再制作新报告，不覆盖旧报告。

## 按什么情况选择报告

| 情况 | 建议使用 | 使用说明 |
|---|---|---|
| 活动日需个人简报 | 日次作業報告書 | 按需采用。短期零散活动可在台账记录后只用周报 |
| 每周检查计划与实际 | 週次進捗報告書 | 作为初始建议的常用汇总；同时需要会议时使用進捗確認会議記録 |
| 长期活动或提交方要求月报 | 月次進捗報告書 | 汇总已有周记录，不重复重填整套任务状态 |
| 到达预先设置的节点评估 | マイルストーン確認記録、マイルストーン報告書 | 前者记录证据与判断，后者向接收者报告结果和下一阶段安排 |
| 要求个人或学科连携活动报告 | 個人貢献報告書、学科連携活動報告書 | 使用真实任务和成果证明，区分个人承担和团队共同成果 |
| 一个活动阶段结束 | 振り返り報告書 | 区分事实、原因推断和改善建议，写明下一行动与担当 |

无需每次填写全部报告。实际频率、收件人和提交期限由团队与老师确定；本包没有虚构这些决定。

## 工时和完成率

进度台账中的「完了予測工数」为实际工时加剩余估计；「工数差」相对原始估计。周负荷按配分工时除以可用工时查看。可用工时、估计或日期未填写时，先处理提示，不把空白当作已经完成或没有风险。

汇总的确认完成率按已有台账定义计算，以已确认成果的基准估计工时计权，不等于个人绩效、玩家体验或质量分数。成果完成必须有人按事先的完成条件确认；自动汇总不能替代确认。成果版本可写在成果物说明或证据路径中。需要延期或换人时使用「遅延と担当変更記録」，将其完整记录名写入 WBS 的关联调整栏。

WBS 的「実績(h)」是每项任务的累计实际工时，不能直接当作日报、周报或月报的本期工时。本期工时使用本期实际活动记录；采用累计差值时，须保留同一任务期初和期末的记录及各自截止时间，以期末累计减期初累计计算。缺少记录时标为未确认，不能用当前累计或估计值冒充本期实绩。

## 命名与保存

文件名称和文书引用使用完整名称，不使用 F01、M02 等文书编号。成员、任务、里程碑和交接 ID 用于关联实际记录，保留这些标识。

保留空白模板，另存活动用副本。可采用「週次進捗報告書_対象期間_文書版.docx」这类可读名称；同一报告的修改提高版本，已提交副本保留。实际成果及其存放地址由团队填写，不要求本包以外的企划或仕様书才能开始管理。

## 文件一览

### 人员管理

- [チーム運営規程](./人员管理/チーム運営規程.docx)：人員と作業の記録、進捗確認、連絡、担当交代の運用を定める。
- [職務役割定義書](./人员管理/職務役割定義書.docx)：担当範囲、判断責任、相談先と代行条件を確認する。
- [参加条件確認と受入記録](./人员管理/参加条件確認と受入記録.docx)：参加可能期間、連絡方法、稼働条件と確認事項を記録する。
- [引継書](./人员管理/引継書.docx)：担当変更や不在時に現状、残作業、期限、証拠と受領を引き継ぐ。
- [人員管理台帳](./人员管理/人員管理台帳.xlsx)：メンバー、担当責任と引継の現状を一度だけ記録する。

### 进度确认

- [作業依頼書](./进度确认/作業依頼書.docx)：依頼する作業、担当、期限、予定工数と完了確認条件を明確にする。
- [進捗確認会議記録](./进度确认/進捗確認会議記録.docx)：台帳の現状を確認し、差異、困り事、次の行動と責任を記録する。
- [遅延と担当変更記録](./进度确认/遅延と担当変更記録.docx)：遅延や担当変更の影響、調整案、決定、担当と新しい予測を記録する。
- [マイルストーン確認記録](./进度确认/マイルストーン確認記録.docx)：事前の到達条件に対する証拠と判断、残作業を記録する。
- [制作計画進捗台帳](./进度确认/制作計画進捗台帳.xlsx)：作業、日程、予定配分、利用可能時間と進捗集計の正本を維持する。
- [文書管理台帳](./进度确认/文書管理台帳.xlsx)：本書式群の保存場所と実運用版、報告の確認と提出受領を管理する。

### 报告用书类

- [日次作業報告書](./报告用书类/日次作業報告書.docx)：当日の作業、実績、困り事と次の行動を担当者が報告する。
- [週次進捗報告書](./报告用书类/週次進捗報告書.docx)：対象週の計画と実績、差異、調整と次週予定を集約する。
- [月次進捗報告書](./报告用书类/月次進捗報告書.docx)：月間の人員と進捗の変化、累積の差異と翌月方針を報告する。
- [マイルストーン報告書](./报告用书类/マイルストーン報告書.docx)：節目の確認結果、到達状況、残作業と次段階の予定を報告する。
- [個人貢献報告書](./报告用书类/個人貢献報告書.docx)：担当した作業と確認済み成果、連携内容と学びを証拠付きで整理する。
- [学科連携活動報告書](./报告用书类/学科連携活動報告書.docx)：学科間の担当、活動実績、連携上の課題と次の対応を報告する。
- [振り返り報告書](./报告用书类/振り返り報告書.docx)：人員と進捗の運用で起きた事実、原因の見立てと改善行動を整理する。

## 设计依据与核查范围

本包沿用此前由用户提供的公司资料审阅结果及已制作书式，针对本轮人员、进度和报告范围重新整理。它是自用书式，不声称为任何日本游戏公司的统一内部标准。本次不改动 H 盘参考原件，也不将原公司的项目实数据复制到模板中。

交付检查记录见「制作核查记录.md」。检查模板的内容、版面、计算和目录，不能替代对实际成员、任务、游戏成果或提交事实的确认。
